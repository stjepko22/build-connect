# buildConnect-react-web-app

React + TypeScript + MobX frontend za BuildConnect aplikaciju.

## Pokretanje

```powershell
npm install
npm run dev
```

Frontend se dize na:

```text
http://localhost:3000
```

## Backend konekcija

Development API URL:

```text
http://localhost:56602/api
```

To je definirano u:

- `.env.development`

## Build

```powershell
npm run build
```

## Napomena

Za puni rad aplikacije backend mora biti pokrenut.
